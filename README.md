## 🚀 Featured project

### [Gestor de Oficina](https://github.com/KestnerFaria/gestor-oficina) — auto repair shop management SaaS
Multi-tenant SaaS **in production**, with paying customers and recurring billing.

- Service orders, inventory with automatic stock deduction (PostgreSQL triggers), payments and customer portal
- Role-based access (admin, front desk, mechanic) and strict tenant isolation
- Monthly subscriptions with free trial via the Asaas API and webhooks
- Migrated from JavaScript to strict TypeScript, finding and fixing 5 production bugs along the way
- CI with GitHub Actions

`React` `TypeScript` `Node.js` `Express 5` `PostgreSQL` `JWT`
